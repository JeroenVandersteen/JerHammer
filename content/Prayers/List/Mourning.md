### Mourning

_During a period of mourning, your devotee remains in the twilight between living and dead._

| Mourning |
| :--- |
| **Level:** 2 |
| **Invoking TN:** 17 |
| **Type:** Heal |
| **Duration:** rounds |
| **Range:** Touch |
| **Target:** 1 |
| **Effect:** For the duration of the prayer, the target does not need to make endurance tests when at 0 HP to check for dieing. |

For the duration of the prayer, the target does not need to make endurance tests when at 0 HP to check for dieing. For the duration of the prayer, the target devotee does not need to make endurance tests when at 0 HP to check for dieing.
