### Crucifixion

_The heretic is crucified for their sins._

| Crucifixion |
| :--- |
| **Level:** 4 |
| **Invoking TN:** 21 |
| **Type:** Offense |
| **Duration:** rounds |
| **Range:** Short |
| **Target:** 1 |
| **Effect:** Make opposed pray vs courage test at start of each of invokter's turns to keep the target in restrained condition. |

Make opposed pray vs courage test at start of each of invokter's turns to keep the target in restrained condition. Choose a target heretic in a short range distance. Make an opposed pray test against the target's courage test at start of each of invoker's turns for the duration of the prayer. If successful the target is kept in restrained condition until the start of the invoker's next turn.
