### Ironclad faith

_Your devotees are protected by an ironclad faith._

| Ironclad faith |
| :--- |
| **Level:** 1 |
| **TN:** 15 |
| **Type:** Buff |
| **Duration:** rounds |
| **Range:** Short |
| **Target:** 1-4 |
| **Effect:** Gain ward (6+) against non-magical attacks. Cost 1 faith point per target protected. |

Gain ward (6+) against non-magical attacks. Cost 1 faith point per target protected. You may choose up to 4 targets, which may include yourself. Each target gains a ward (6+) against non-magical attacks for the duration of the prayer. The cost of the prayer is 1 faith point per target protected.
