### Bolt of Fear

| Bolt of Fear |
| :--- |
| **Lore:** Mind |
| **CN:** 6 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** 1 |
| **Damage:** 4d6 L/i, fear condition |
| **Armor:** AP/IR counts |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 4d6 L/i, fear condition (AP/IR counts) to 1 target at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
