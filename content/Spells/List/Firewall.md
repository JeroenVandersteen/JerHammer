### Firewall

_Conjuring a barrier of roaring flames, obstructing passage and repelling foes with intense heat._

| Firewall |
| :--- |
| **Level:** 3 |
| **Lore:** Heavenly Elements |
| **Casting TN:** 19 |
| **Type:** Combat |
| **Duration:** rounds |
| **Range:** Short |
| **Target:** Area |
| **Damage:** 4d6 L |
| **Armor:** AP counts |
| **Effect:** Combat spell. Wall is WP x 1 x 2 meters, ablaze condition and 4d6 L (AP counts) when crossing |

This spell deals 4d6 L (AP counts) to all creatures in an area at short range each round, for WP rounds. The caster erects a wall of flame with dimensions equal to their Willpower (WP) meters long by 1 by 2 meters. Any creature crossing the wall suffers 2d6 L (Lethal) damage, Armor Points count. Additionally, creatures that come into contact with the wall are inflicted with the ablaze condition.
