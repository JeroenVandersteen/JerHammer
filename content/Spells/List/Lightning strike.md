### Lightning strike

| Lightning strike |
| :--- |
| **Level:** 4 |
| **Lore:** Heavenly Elements |
| **Casting TN:** 21 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** 1 |
| **Damage:** 7d6 L |
| **Armor:** AP ignored |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 7d6 L (AP ignored) to 1 target at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
