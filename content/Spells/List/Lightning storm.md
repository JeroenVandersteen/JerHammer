### Lightning storm

| Lightning storm |
| :--- |
| **Lore:** Lore Of Heavens |
| **CN:** 9 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** Area |
| **Damage:** 3d6 L |
| **Armor:** AP ignored |
| **Resist:** Spell TN |
| **Effect:** Combat spell. Lightning shoots out in all directions |

This spell deals 3d6 L (AP ignored) to all creatures in an area at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
