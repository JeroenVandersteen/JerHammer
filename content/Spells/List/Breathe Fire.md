### Breathe Fire

_Unleashing a torrent of flames from the caster's breath, scorching everything in its path._

| Breathe Fire |
| :--- |
| **Lore:** Heavenly Elements |
| **CN:** 9 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Self |
| **Target:** Area |
| **Damage:** 4d6+1 L, ablaze condition |
| **Armor:** AP counts |
| **Resist:** Dodge TN |
| **Effect:** Combat spell.  |

This spell deals 4d6+1 L, ablaze condition (AP counts) to the caster themselves. The spellcast check has to also be equal to or higher than the target's Dodge TN.
