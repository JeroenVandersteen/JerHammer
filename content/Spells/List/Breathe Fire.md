### Breathe Fire

_Unleashing a torrent of flames from the caster's breath, scorching everything in its path._

| Breathe Fire |
| :--- |
| **Level:** 4 |
| **Lore:** Fire Element |
| **Casting TN:** 19 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** Area |
| **Damage:** 6d6 L, ablaze condition |
| **Armor:** AP counts |
| **Resist:** Ranged TN |
| **Effect:** Combat spell.  |

This spell deals 6d6 L, ablaze condition (AP counts) to all creatures in an area at short range instantly. The spellcast check has to also be equal to or higher than the target's Ranged TN.
