### Drain

| Drain |
| :--- |
| **Lore:** Petty Magic |
| **CN:** 0 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Touch |
| **Target:** 1 |
| **Damage:** 1d6 L |
| **Armor:** AP counts |
| **Heal:** 1 HP |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 1d6 L (AP counts) to 1 target touched instantly. The spellcast check has to also be equal to or higher than the target's Spell TN. The caster then heals 1 HP.
