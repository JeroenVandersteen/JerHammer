### Death Touch

| Death Touch |
| :--- |
| **Level:** 3 |
| **Lore:** Death |
| **Casting TN:** 19 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Touch |
| **Target:** 1 |
| **Damage:** 6d6 L |
| **Armor:** AP ignored |
| **Heal:** 1d6 HP |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 6d6 L (AP ignored) to 1 target touched instantly. The spellcast check has to also be equal to or higher than the target's Spell TN. The caster then heals 1d6 HP.
