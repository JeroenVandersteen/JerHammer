### Create bridge

_In the realm where dreams and reality intertwine, a bridge of shimmering light spans the gap, a path forged by the mage's will to defy the limits of the mundane._

| Create bridge |
| :--- |
| **Lore:** Terrestrial Elements |
| **CN:** 3 |
| **Type:** Utility |
| **Duration:** rounds |
| **Range:** Touch |
| **Effect:** Create bridge with length WP meter (+1m per overcasting) |

 The caster creates a bridge of magical energy with a length equal to their Willpower in meters, with an additional meter for each overcasting.
