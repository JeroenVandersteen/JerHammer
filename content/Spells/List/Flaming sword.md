### Flaming sword

_Enchanting a blade with roaring flames, turning it into a deadly weapon that burns through flesh and armor alike._

| Flaming sword |
| :--- |
| **Level:** 2 |
| **Lore:** Fire Element |
| **Casting TN:** 17 |
| **Type:** Enchantment |
| **Duration:** rounds |
| **Range:** Touch |
| **Effect:** One weapon becomes flaming, cause ablaze on hit |

 The caster enchants one weapon, causing it to burst into flames upon contact. Any successful hits with the weapon cause the ablaze condition to be inflicted upon the target, dealing additional fire damage over time.
