### Thunderstorm

| Thunderstorm |
| :--- |
| **Lore:** Lore Of Heavens |
| **CN:** 9 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** Area |
| **Damage:** 2d6 i, stunned, prone |
| **Armor:** IR counts |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 2d6 i, stunned, prone (IR counts) to all creatures in an area at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
