### Blinding Light

| Blinding Light |
| :--- |
| **Level:** 2 |
| **Lore:** Light |
| **Casting TN:** 17 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** Area |
| **Damage:** blinded condition |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals blinded condition to all creatures in an area at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
