### Conundrum

| Conundrum |
| :--- |
| **Level:** 1 |
| **Lore:** Mind |
| **Casting TN:** 15 |
| **Type:** Hex |
| **Duration:** instant |
| **Range:** Short |
| **Target:** Area |
| **Damage:** 1d6 i, stunned condition |
| **Armor:** IR ignored |
| **Resist:** Spell TN |
| **Effect:** Hex spell. Overwhelm foes with confusion and indecision |

This spell deals 1d6 i, stunned condition (IR ignored) to all creatures in an area at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
