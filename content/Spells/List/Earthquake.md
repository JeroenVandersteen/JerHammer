### Earthquake

| Earthquake |
| :--- |
| **Level:** 4 |
| **Lore:** Terrestrial Elements |
| **Casting TN:** 19 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** Area |
| **Damage:** 7d6 i, prone |
| **Armor:** IR counts |
| **Resist:** Ranged TN |
| **Effect:** Combat spell.  |

This spell deals 7d6 i, prone (IR counts) to all creatures in an area at short range instantly. The spellcast check has to also be equal to or higher than the target's Ranged TN.
