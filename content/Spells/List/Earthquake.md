### Earthquake

| Earthquake |
| :--- |
| **Lore:** Terrestrial Elements |
| **CN:** 9 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** Area |
| **Damage:** 5d6 i, prone |
| **Armor:** IR counts |
| **Resist:** Dodge TN |
| **Effect:** Combat spell.  |

This spell deals 5d6 i, prone (IR counts) to all creatures in an area at short range instantly. The spellcast check has to also be equal to or higher than the target's Dodge TN.
