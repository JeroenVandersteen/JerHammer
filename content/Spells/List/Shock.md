### Shock

| Shock |
| :--- |
| **Lore:** Heart |
| **CN:** 3 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Touch |
| **Target:** 1 |
| **Damage:** 5d6 i, stunned condition |
| **Armor:** IR counts |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 5d6 i, stunned condition (IR counts) to 1 target touched instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
