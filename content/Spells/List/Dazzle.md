### Dazzle

| Dazzle |
| :--- |
| **Lore:** Petty Magic |
| **CN:** 0 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** 1 |
| **Damage:** blinded condition |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals blinded condition to 1 target at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
