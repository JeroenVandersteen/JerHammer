### Weinwurm's Daemonbane

_You can on the holy light to banish a demon entirely._

| Weinwurm's Daemonbane |
| :--- |
| **Level:** 4 |
| **Lore:** Light |
| **Casting TN:** 21 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** 1 |
| **Damage:** 9d6 L |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 9d6 L to 1 target at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
