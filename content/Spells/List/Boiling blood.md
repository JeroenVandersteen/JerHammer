### Boiling blood

_The target's blood starts boiling for the whole duration of the spell._

| Boiling blood |
| :--- |
| **Level:** 3 |
| **Lore:** Heart |
| **Casting TN:** 17 |
| **Type:** Combat |
| **Duration:** rounds |
| **Range:** Short |
| **Target:** 1 |
| **Damage:** 7d6 L |
| **Armor:** AP ignored |
| **Resist:** Spell TN |
| **Effect:** Combat spell. Target must make opposed endurance vs language magick or suffer damage each turn |

This spell deals 7d6 L (AP ignored) to 1 target at short range each round, for WP rounds. The spellcast check has to also be equal to or higher than the target's Spell TN. The target's blood starts boiling, causing excruciating pain and dealing ongoing damage for the spell's duration. Each round, the target must make a successful Spell resistance test (TN 16) or suffer 2d6 L (Lethal) damage, ignoring Armor Points, until the spell ends or they receive appropriate medical attention.
