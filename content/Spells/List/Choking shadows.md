### Choking shadows

| Choking shadows |
| :--- |
| **Level:** 2 |
| **Lore:** Darkness |
| **Casting TN:** 15 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Short |
| **Target:** 1 |
| **Damage:** 6d6 i, fatigue |
| **Armor:** IR counts |
| **Resist:** Spell TN |
| **Effect:** Combat spell. Target gains fatigue if they need to breathe, and cannot speak for rounds |

This spell deals 6d6 i, fatigue (IR counts) to 1 target at short range instantly. The spellcast check has to also be equal to or higher than the target's Spell TN.
