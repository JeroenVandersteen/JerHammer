### Drain Life

| Drain Life |
| :--- |
| **Lore:** Death |
| **CN:** 0 |
| **Type:** Combat |
| **Duration:** instant |
| **Range:** Touch |
| **Target:** 1 |
| **Damage:** 3d6 L |
| **Armor:** AP counts |
| **Heal:** 1d6 HP |
| **Resist:** Spell TN |
| **Effect:** Combat spell.  |

This spell deals 3d6 L (AP counts) to 1 target touched instantly. The spellcast check has to also be equal to or higher than the target's Spell TN. The caster then heals 1d6 HP.
