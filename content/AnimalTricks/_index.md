# Animal Tricks


## Animal Tricks

| Trick | Short Description |
| :--- | :--- |
| [Flanking attack](<AnimalTricks/List/Flanking attack>) | Once per encounter: 1 advantage to melee attack to hit |
| [Viscious attack](<AnimalTricks/List/Viscious attack>) | Give +1 L damage on melee |
| [Protect](<AnimalTricks/List/Protect>) | Once per encounter: 1 disadvantage to opponent's melee |
| [Take hit](<AnimalTricks/List/Take hit>) | Once per encounter: animal takes damage of 1 hit |
| [Trip](<AnimalTricks/List/Trip>) | Once per encounter: on succesful melee hit, trip instead of damage |
| [Grapple](<AnimalTricks/List/Grapple>) | Once per encounter: advantage to grapple |
| [Fetch](<AnimalTricks/List/Fetch>) | Go fetch small objects |
| [Snatch](<AnimalTricks/List/Snatch>) | Make opposed Strength test to snatch object from hand |
| [Message](<AnimalTricks/List/Message>) | Bring a message (small scroll or small object) |
| [Track](<AnimalTricks/List/Track>) | Advantage on tracking (replaces any other bonuses) |
| [Scout](<AnimalTricks/List/Scout>) | Advantage no perception for spotting hidden enemies |
| [Guard](<AnimalTricks/List/Guard>) | Cannot be surprised |
| [Intimidate](<AnimalTricks/List/Intimidate>) | Advantage on intimidation |
| [Entertain](<AnimalTricks/List/Entertain>) | Advantage on entertainment/performance |
| [Distract](<AnimalTricks/List/Distract>) | Advantage to provide distraction |
| [Burden](<AnimalTricks/List/Burden>) | Animal carries cargo |
| [Mount](<AnimalTricks/List/Mount>) | The animal accepts a rider |
| [Nimble Escape](<AnimalTricks/List/Nimble Escape>) | Animal gains advantage to resist grapple and hide |

| [Familiar - telepathy](<AnimalTricks/List/Familiar - telepathy>) | Caster may communicate telepathically with the familiar |
| [Familiar - dexterity](<AnimalTricks/List/Familiar - dexterity>) | Familiar may use items, open doors, feed potions, spread caltrops,... |
| [Familiar - regeneration](<AnimalTricks/List/Familiar - regeneration>) | Familiar regenerates 1d6 HP per turn |
